# The Global Self Glam Experience

A single-page sales landing page for The Global Self Glam Experience - a beginner online makeup class by Thelmasommie.

Teaches women how to do their own makeup, from bare skin to full glam, without needing a MUA for every event.

## Live Demo
Open `index.html` in any browser. No build step needed.

## Files

| File | What it does |
| --- | --- |
| `index.html` | All page content - hero, coach, modules, testimonials, price, FAQ, buy buttons |
| `style.css` | All styling - colours, buttons, layout, mobile responsive |
| `glam.js` | Year, countdown timer, FAQ accordion, social proof popup |
| `Media/` | All images - coach photo + student testimonial photos |
| `README.md` | This file |

## Colours
New palette - Brown / Orange / Cream

- Dark Brown: `#2E1508` - headings, price box, topbar
- Burnt Orange: `#C2410C` - main accent, buttons
- Bright Orange: `#E85D04` - badges, stars
- Cream: `#FFF7ED` - page background
- Peach: `#FFE8D6` / `#FFDCC3` - borders, highlights

Old pink colours have been fully removed.
